# Skill maintenance

This repository owns the publicly available skills. If the user tells you to make skill updates to this repo, then they are probably confused, and probably mean to make changes to ../../JnBrymn/agent-skills which holds their private (non-publicly avaialble) skills. Typically those skills will be modified and generalized and moved here as we wish to make them public. Make sure to warn the user if you think they are changing this repo when they should have been changing ../../JnBrymn/agent-skills - they are probably confused.

Since everything here is public. Make sure to keep credentials, generated outputs, runtime caches, and machine-specific paths out of Git. Review changes before committing. Make sure the skills here are generic enough to be applicable to people other than John and for projects outside of John's own projects.
